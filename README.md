# Multimodal AI Chatbot

A beginner-level multimodal AI chatbot built using Python, FastAPI and PostgreSQL.

## Features

- Text-based AI chat
- Image understanding
- Document upload
- PDF support
- DOCX support
- TXT support
- Markdown support
- RAG architecture
- Web search
- Document creation
- Document updating
- Conversation history
- Emotional assistance
- PostgreSQL database

## Technology Stack

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Python
- FastAPI

### Database

- PostgreSQL

### AI

- OpenAI API

### RAG

- Text chunking
- Embeddings
- Similarity retrieval
- Context-based generation
